# Dorkari Shopping — ই-কমার্স ওয়েবসাইট

**ফেজ ১ + ফেজ ২-এর শুরু:** প্রজেক্ট কাঠামো, ডিজাইন সিস্টেম, মোবাইল-ফার্স্ট হোমপেজ, পণ্যের পেজ, সার্চ/ফিল্টার, কার্ট।

> ⚠️ এই কোড আমার এখানকার পরিবেশে চালিয়ে দেখা যায়নি (ইন্টারনেট বন্ধ থাকায় প্যাকেজ ইনস্টল করা যায়নি)।
> তাই প্রথমবার চালানোর সময় কোনো এরর এলে এররটা কপি করে আমাকে পাঠাও, আমি ঠিক করে দেব।

## একবারের সেটআপ (কম্পিউটারে)

1. **Node.js** ইনস্টল করো: https://nodejs.org থেকে "LTS" ভার্সন (১৮ বা তার বেশি)।
2. ফোল্ডারটা আনজিপ করে টার্মিনাল (Windows-এ PowerShell/CMD) খোলো এবং ফোল্ডারে ঢোকো:
   ```
   cd dorkari-shopping
   ```
3. প্যাকেজ ইনস্টল:
   ```
   npm install
   ```
4. ডেভেলপমেন্ট সার্ভার চালু:
   ```
   npm run dev
   ```
5. ব্রাউজারে খোলো: http://localhost:3000  (মোবাইলে দেখতে ব্রাউজারের "Responsive/Mobile" মোড ব্যবহার করো)।

বন্ধ করতে টার্মিনালে `Ctrl + C`।

## এখন কী কী কাজ করে
- হোমপেজ: অ্যানাউন্সমেন্ট বার, লোগো + সার্চ, কার্ট আইকনে লাইভ সংখ্যা, হিরো ব্যানার, ক্যাটাগরি, ফ্ল্যাশ সেল কাউন্টডাউন, বেস্ট সেলিং, নতুন, ফিচার্ড, ঘর-গৃহস্থালি, অফার, রিভিউ, ফুটার।
- নিচের স্টিকি নেভিগেশন (মোবাইলে): হোম, ক্যাটাগরি, সার্চ, কার্ট, অ্যাকাউন্ট।
- পণ্যের ডিটেইল পেজ, সার্চ + ক্যাটাগরি/দাম ফিল্টার + সর্টিং।
- কার্ট: যোগ/মুছা/পরিমাণ বাড়ানো-কমানো, রিফ্রেশ করলেও থাকে, স্টকের বেশি অর্ডার করা যায় না।

## নমুনা তথ্য
`lib/sample-data.ts`-এর সব পণ্য **নমুনা**। তিনটা পণ্যে তোমার আসল অ্যাড ছবি আছে; বাকিগুলোর দাম/স্টক উদাহরণ মাত্র। ফেজ ৩-এ ডাটাবেস যুক্ত হলে এগুলো সরে যাবে।

## যেসব তথ্য আমি বানাইনি
ফোন নম্বর, হোয়াটসঅ্যাপ, ইমেইল, ঠিকানা, ডেলিভারি চার্জ, রিটার্ন নীতি, বিকাশ/নগদ নম্বর — সবই ফাঁকা (`lib/site-config.ts`)। ফেজ ৬-এ অ্যাডমিন সেটিংস থেকে বসাবে।
